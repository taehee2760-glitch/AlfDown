# AlfDown 5.0 — Orchestra Edition

윈도우용 악보 이미지 검색·다운로드·악기별 PDF 제작 프로그램.

## 설치 및 빌드
1. 이 ZIP을 압축 해제합니다.
2. GitHub 저장소 **최상위**에 `S3_downloader.py`, `treble.ico`를 올립니다.
3. `.github/workflows/build.yml` 파일을 GitHub 웹의 Create new file로 생성하거나 기존 파일을 교체합니다.
4. Actions → Build AlfDown Windows EXE → Artifacts → AlfDown-Windows에서 EXE를 받습니다.
5. EXE 사용자는 Python 설치가 필요하지 않습니다.

## 검색 규칙
- 악기: `상품번호_악기코드파트-페이지.png` (예: `00-PC-0019403_VN2-3.png`)
- SB, BC, TMP, K, 하프 H: `상품번호_악기코드-페이지.png`
- 호른 H: `상품번호_H파트-페이지.png`
- 스코어 전용: `상품번호-페이지.png` (예: `00-PC-0019403-1.png`)
- 서버 목록을 가져오는 방식이 아니라 지정된 후보 URL을 검사합니다. 서버에서 HEAD 요청을 차단할 경우 실제 파일이 누락될 수 있습니다.

## PDF 정렬
현악기: 바이올린(VN) → 비올라(VA) → 첼로(VC) → 스트링베이스(SB)
목관악기: 피콜로(P) → 플루트(F) → 오보에(O) → 클라리넷(C) → 베이스클라리넷(BC) → 바순(B)
금관악기: 호른(H) → 트럼펫(T) → 트롬본(TN) → 튜바(TB)
타악기 외: 말렛(M) → 팀파니(TMP) → 퍼커션(PC) → 피아노(K) → 하프(H)
각 악기별 파트 번호 → 페이지 번호 순으로 정렬합니다. 스코어는 별도 PDF입니다.

PDF 생성은 **현재 프로그램 실행에서 다운로드 완료된 파일**을 대상으로 합니다. 원본 이미지는 수정하지 않습니다. 출판사 워터마크는 제거하지 않습니다.

## 주의
Windows에서 실제 실행과 원격 서버 접근은 이 환경에서 검증하지 못했습니다. 악보 및 이미지 사용 권한을 확인하세요.


### 5.1 추가 기능
- 저장 폴더 옆 **📂 저장 폴더 열기** 버튼으로 Windows 탐색기에서 즉시 폴더를 엽니다.
- 지정한 폴더가 없으면 자동 생성한 후 엽니다.
