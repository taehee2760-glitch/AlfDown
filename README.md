# AlfDown 4.0

Windows EXE 자동 빌드 프로젝트. Python 설치 없이 생성된 EXE 실행 가능.

## 설치
1. ZIP 압축을 풀고 `S3_downloader.py`를 GitHub 저장소 최상위에 업로드하세요.
2. 기존 `.github/workflows/build.yml`을 ZIP 안의 버전으로 교체하세요. 특히 Pillow 설치가 필요합니다.
3. `.github` 폴더 업로드가 어려우면 GitHub에서 `.github/workflows/build.yml` 파일을 직접 만들고 내용을 붙여넣으세요.
4. Actions → Build Windows EXE → Artifacts → AlfDown-Windows 다운로드.

## 검색
- 파트-페이지: VN1-1, VA2-3 등
- 페이지 전용: SB-1, BC-1, TMP-1, K-1, 하프 H-1
- 호른 H1-1 / 하프 H-1 은 다른 패턴입니다.
- 스코어 다운 전용: 상품번호 + 연결 문자 + 직접 입력한 토큰 + '-' + 페이지번호 (예: `00-PC-0019403_asdf-1.png`).
- 스코어 전용을 체크하면 악기 체크박스 대신 스코어 후보만 검색합니다.
- PDF는 **해당 실행에서 다운로드에 성공한 이미지**를 기준으로 분류별 생성하며 자연 정렬합니다. 스코어는 별도 PDF.
- 기존 PDF와 같은 이름으로 생성 시 덮어씁니다. 원본 이미지는 유지됩니다.
- 실제 서버의 목록 권한/존재 파일은 이 프로젝트에서 보장하지 않습니다.

## 주의
S3 공개 접근 권한이 없으면 검색 불가. HTTP 403은 누락으로 간주하지 않습니다.
검색 중지 시 이미 진행 중인 네트워크 요청은 타임아웃까지 대기할 수 있습니다.
대량의 고해상도 이미지를 PDF로 만들면 메모리를 많이 사용합니다.
